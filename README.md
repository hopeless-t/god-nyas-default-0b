# God Nyāzu Default 0B Asset

Official optional starter asset for **六親合体ゴッドにゃ〜ず / ROKUSHIN GATTAI GOD NYĀZU**.

This repository contains the distributable public 0B starter model. It is separate from the Apache-2.0 licensed God Nyāzu runtime.

```python
from godnyas_default_0b import load_default_0b

model = load_default_0b()
print(model.respond("ベンチ回して"))
```

The bundled public build reports:

- `trainable_parameters = 0`
- `model_calls = 0`
- explicit `UNRESOLVED` outside its bounded surface
